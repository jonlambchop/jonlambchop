# Agent instructions

This codebase is yours: what it's for and how it's built are your call, and you'll keep building on it.

## Build cleanly
Always build code cleanly, modularly, and with proper architecture and separation of concerns. Never simply bolt on a feature because I asked for it. If you can't find an easy way to build it naturally, and you'd recommend a refactor to make the whole thing clean, stop your work ahead of time and say so.
